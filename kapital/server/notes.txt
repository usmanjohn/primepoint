I. Common stuff 
Go to the project root folder and activate the environment to apply some changes.
cd /var/ then cd www/ then cd dashboard then source delta/bin/activate then cd dashboard
sudo journalctl -u gunicorn -f is the log panel


II. Migration: 
/var/www/dashboard/delta/bin/python manage.py makemigrations and migrate

III. Increase the time wait at two places:
   1. sudo nano /etc/systemd/system/gunicorn.service
   2. sudo nano /etc/nginx/sites-available/default
   3. sudo systemctl reload nginx
   4. sudo systemctl daemon-reload
   

IV. Always restart gunicorn after git pull: sudo systemctl restart gunicorn

 



V. Memory (ОЗУ) — gunicorn workers give their memory back (added 2026-11-10)
   Each gunicorn worker is its own Python process and keeps its own big pandas tables.
   With --max-requests a worker restarts after ~N requests and frees all of it.
   1. sudo nano /etc/systemd/system/gunicorn.service
   2. in the ExecStart line, after the other options, add:
          --max-requests 200 --max-requests-jitter 50
      (jitter = workers do not all restart at the same moment)
      Optional, if RAM is still tight: fewer workers, more threads, e.g.
          --workers 2 --threads 4
   3. sudo systemctl daemon-reload
   4. sudo systemctl restart gunicorn
   5. check: systemctl status gunicorn   (must be "active (running)")
             free -h                      (watch "available" over the day)
   Collateral is switched off in collateral/views.py (ENABLED = False). To turn it back
   on: ENABLED = True, then sudo systemctl restart gunicorn.
