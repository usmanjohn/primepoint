# Sonlar imperiyasi — a comic fairy-tale SERIES about the number system
#
# The user's own tale (Zero gravity.docx), rebuilt as a series: every episode a new kind
# of number is born because the old ones could not do something. It is the third maths
# shelf, beside "Prime Math Readings" and "Matematika olami", and like Matematika olami
# it belongs to NO lesson.
#
#   * TWO LAWS: every scene mathematically true; every scene funny — and the joke IS the
#     maths (the twins vanish when they hug because 1 + (−1) = 0).
#   * Episode shape: cold-open joke → problem → comic failure → the new number is born →
#     cliffhanger → «Haqiqatda» box (pe-call pe-tip, real maths + real history) →
#     «Keyingi qismda…» line. 330–500 words; ertak register («…ekan»), lots of dialogue.
#   * cn-word 2–6 per episode (the key terms only), grammar = the episode's one maths idea,
#     2–3 questions (vary `answer`), open_question.
#   * Inline SVG with pm-* classes. NO audio (maths shelf).
#   * All episodes released together (user's choice, 2026-10-05); the weekly rhythm is
#     the Flow Studio videos (GUIDE §2 «Sonlar imperiyasi», ordered).
#   * Facts: every date in a Haqiqatda box is listed in the data file's FAKTLAR header;
#     a legend is called «rivoyat».
