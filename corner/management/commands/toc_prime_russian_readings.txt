# Prime Russian Readings — the third leg of each lesson
#
# Every reading belongs to ONE Prime Russian tutorial and its `order` IS the lesson
# number, so PR-24's reading is order 24. Nothing here stands alone: the tutorial
# teaches the pattern, the practice drills it, the reading shows it living in a text.
#
# ── The three structural rules ──
#
# 1. FOCUS. The reading uses the lesson's own pattern at least twice, and lists it in
#    the story's `grammar` block (StoryGrammar) so it appears under the vocabulary.
#    2-3 natural uses beat 6 forced ones. If the pattern fights the story, use it less
#    and let the story win — a reading nobody enjoys teaches nothing.
# 2. CUMULATIVE. Anything taught in an EARLIER lesson may be used freely; anything
#    from a LATER lesson may not. Check toc_prime_russian.txt before reaching for a
#    pattern. This is why the early readings are short and the later ones read like
#    real Russian.
#
#    ONE EXPLICIT EXCEPTION — the narrative frame. Verbs only arrive properly at
#    PR-19. Until then a story still needs a way to say who did what between the
#    lines of dialogue, so the NARRATION may use this small closed list as plain
#    vocabulary, always with a cn-word gloss:
#        есть · нет · зову́т · живёт · рабо́тает · говори́т · сказа́л / сказа́ла ·
#        пришёл / пришла́ · дал / дала́ · был / была́
#    The DIALOGUE lines stay strictly inside what the lessons have taught — that is
#    where the pupil is meant to recognise the pattern. This is exactly how graded
#    readers work: the frame carries the story, the dialogue carries the grammar.
#    ✅ ISTISNO TUGADI PR-19 da (2026-08-09): feʼl tizimi ochildi, shuning uchun
#    PR-19 dan boshlab matnlarda feʼllar oddiy grammatika sifatida keladi.
#    Faqat oʻsha darsgacha oʻrgatilgan tuslanishdan foydalaning.
# 3. LINKED. After importing a reading, re-run import_tutorials with --republish so
#    the tutorial's `"stories": [...]` key attaches it and the Reading card appears
#    on the lesson page.
#
# ══════════════════════════════════════════════════════════════════════
# ── CLARITY IS THE FIRST RULE (user's rule, 2026-08-08) ──
#
# The user is learning Russian from these texts himself. A learner reading a
# foreign language has no spare attention for working out WHO did WHAT. So:
#
#   * NAME the character in the first sentence, and keep using the name. Do not
#     drift into "он" / "она" for six sentences — a beginner loses the thread.
#     Two characters of the same gender in one paragraph = always use names.
#   * CHRONOLOGICAL ORDER. Events happen in the order they are written. No
#     flashbacks, no "but earlier that morning…", no jumping between two places
#     in one paragraph, before PR-66.
#   * ONE THING PER SENTENCE. Short sentences. A new action gets a new sentence.
#   * SAY THE OBVIOUS. Russian drops the subject and the verb "to be" happily;
#     in these readings, don't. Write Ди́ма пришёл домо́й, not just Пришёл.
#   * NO UNEXPLAINED JUMPS. If the scene moves, say so: На сле́дующий день…,
#     Ве́чером…, В шко́ле…  A time/place word at the head of a paragraph is cheap
#     and it saves the reader every time.
#   * The ENDING must land. The reader should be able to say in one sentence what
#     happened and why it mattered. If Claude cannot summarise it in one Uzbek
#     sentence, rewrite it.
#   * Test before shipping: read it once as someone who knows 300 Russian words.
#     Anywhere you would pause and re-read — fix it.
#
# ── VERSATILE, AND SOURCE IT FROM ANYWHERE (user's rule, 2026-08-08) ──
#
# The stories do NOT all have to be invented. Any of these is welcome, and the
# genre should ROTATE — never three of the same shape in a row:
#
#     kundalik hikoya (everyday scene)      xat (a letter)
#     kundalik daftar (diary entry)         suhbat (a real dialogue)
#     rus xalq ertagi (folk tale, retold)   ilmiy-ommabop matn (how X works)
#     yangilik xabari (short news item)     qoʻllanma / retsept (instructions)
#     sayohat qaydlari (travel notes)       biografiya (a real person's life)
#     sirli hikoya (a small mystery)        sharh (a review — film, café, book)
#     intervyu (Q&A)                        tarix (a historical episode)
#     hazil / anekdot (light, kind ones)    maktub-javob (letter + reply)
#
# Retelling real material is encouraged where it is clearer than invention:
# Russian folk tales (Репка, Колобок, Маша и медведь…), the life of a real
# scientist or writer, how the Trans-Siberian was built, why Baikal is deep.
# Facts must be true. When a text is a retelling, say so in the Uzbek `summary`.
#
# Modern and everyday is good: phones, buses, cafés, group chats, part-time jobs,
# exams, delivery food, sharing a charger. Keep it light and kind.
# ══════════════════════════════════════════════════════════════════════
#
# ── Length curve (guide, not a rule) ──
#   PR-6  … PR-18   40–70 words     4–7 sentences, tiny scenes and dialogues
#   PR-19 … PR-40   70–130 words    a small scene with a beginning and an end
#   PR-41 … PR-65   130–190 words   connected paragraphs, past tense, quoted speech
#   PR-66 … PR-100  190–280 words   real B1/B2 length and register
#
# ── Language policy (mirror of Prime Korean) ──
#   Story text, title and characters: RUSSIAN.
#   `summary`, `cn-word data-tr` glosses, `grammar` meanings and question
#   `explanation`s: UZBEK. Questions themselves: UZBEK.
#   No English anywhere.
#
# ── Stress marks in the body ──
#   PR-6 … PR-20: mark the stress on every multi-syllable word — the pupil is
#   still learning to read. PR-21 … PR-50: new and stress-shifting words only.
#   PR-51 onward: only genuinely hard or ambiguous words. Never on ё.
#
# ── Vocabulary ──
#   Mark new words inline: <span class="cn-word" data-tr="tarjima">сло́во</span>
#   6–10 marks in early readings, 10–16 up to PR-55, 20–32 from PR-56 where the
#   texts are long narratives. Mark real new words, not words the pupil has met.
#   data-pos: verb / adj / adv.
#   Never put a cn-word inside a <strong>. Bold the focus pattern with <strong>
#   where it appears — house style of the Prime collections.
#   Names: the user's pupils (Afsona, Jasur, Sherbek, Dilnoza, Bekzod → Афсона,
#   Жасур, Шербек, Дилноза, Бекзод) alongside Russian names (Анна, Дмитрий,
#   Марина, Олег, Катя, Ни́на, Серге́й).
#
# ── Questions ──
#   2–3 `questions` (StoryQuestion MCQs), in Uzbek, at least one testing whether
#   the reader actually understood the focus grammar rather than just the plot.
#
# ══════════════════════════════════════════════════════════════════════
# ── NO AUDIO ON THIS COLLECTION (user's decision, 2026-08-09) ──
#
# ⛔ Do NOT run gen_corner_audio or import_corner_audio for Prime Russian
#    Readings. Do not offer it, do not add it back into the batch workflow.
#
# The first three readings (PR-6…PR-8) were generated with edge-tts using both
# Russian voices (ru-RU-SvetlanaNeural / ru-RU-DmitryNeural, including the
# two-voice --speaker-voices trick for dialogues). The user listened and
# rejected them: "it is reading very strange, maybe their tts is not good
# enough for russian yet." The Korean and English collections keep their audio;
# Russian gets none until a better Russian voice exists.
#
# CONSEQUENCE FOR WRITING — this is the useful part:
# The readings no longer have to be shaped for a narrator. The early entries
# were written as strictly-alternating one-speaker-per-<p> dialogues purely so
# --speaker-voices could split them. THAT CONSTRAINT IS GONE. Mix narration and
# dialogue freely, put a narration line between two quoted turns, use as many
# characters as the story needs, let a scene breathe. The only rules left are
# CLARITY and VERSATILITY above — and those are the ones that mattered anyway.
#
# A batch is therefore: 3 tutorials + 3 practices + 3 readings. That is all.
# ══════════════════════════════════════════════════════════════════════
#
