# Prime Math Readings — the third leg of each lesson
#
# Every reading belongs to ONE Prime Math lesson and its `order` IS the lesson number,
# so PM-23's reading is order 23. Nothing here stands alone: the tutorial teaches the
# idea, the practice drills it, the reading shows it doing real work in a text.
#
# ══════════════════════════════════════════════════════════════════════
# ── WHY THIS COLLECTION EXISTS ──
#
# A pupil who can compute but cannot read a problem fails every exam that matters.
# The gap between "hisobla: 240 000 × 0,3" and "Afsona pulining 30 foiziga kitob oldi,
# kitob necha soʻm turdi?" is a READING gap, not a maths gap. This shelf is where that
# gap is closed — and it is why the user asked for it: "please do not just give
# numerical questions, you know text also is important".
#
# So a reading here is a real text that HAPPENS to contain the lesson's maths, never a
# word problem with a paragraph glued on top.
#
# ── HOW CORNER'S MACHINERY IS REUSED (this is the whole trick) ──
#
#   cn-word span   →  ATAMA, not a translation.
#                     <span class="cn-word" data-tr="butunning teng boʻlaklaridan biri
#                     yoki bir nechtasi">kasr</span>
#                     data-tr holds a short UZBEK DEFINITION. The end-of-story
#                     flashcards therefore become a term drill: atama → taʼrif.
#                     Terms only — never gloss ordinary words like "bozor" or "keldi".
#                     Never put a cn-word inside a <strong>.
#
#   grammar block  →  QOIDA / FORMULA that the text used.
#                     {"pattern": "sonning p foizi = son × p ÷ 100",
#                      "meaning": "Foiz — yuzdan boʻlak. 30% = 0,30 = 30/100.",
#                      "examples": ["240 000 × 0,3 = 72 000",
#                                   "240 000 − 72 000 = 168 000 (chegirmadan keyingi narx)"]}
#                     1–2 entries. The `examples` lines are the arithmetic the story
#                     actually did, so the reader can check themselves.
#
#   questions      →  2–3 MCQs, in Uzbek. ALWAYS this mix:
#                     • 1 tushunish savoli — who/what/why, answerable only by reading;
#                     • 1–2 HISOB savoli — the reader must compute from the numbers in
#                       the text. The distractors are the real wrong moves (wrong
#                       operation, wrong percentage base, forgotten unit).
#                     Every `explanation` shows the work, in Uzbek.
#                     ⚠️ Story questions are rendered in STORED ORDER (unlike the
#                     practice tests, which are shuffled by display_choices()). So
#                     VARY `answer` by hand — never leave every correct option at
#                     index 0, or a pupil scores without reading. Numeric options
#                     stay in ascending order and the answer lands where it lands.
#
# ── The three structural rules ──
#
# 1. FOCUS. The reading uses the lesson's own maths and names it in the `grammar` block.
#    Two natural uses beat six forced ones. If the maths fights the story, use it less
#    and let the story win — a reading nobody enjoys teaches nothing.
# 2. CUMULATIVE. Anything from an EARLIER lesson may be used freely; anything from a
#    LATER lesson may not. Check toc_prime_math.txt before reaching for a tool: PM-17's
#    reading may not lean on foiz (PM-23) or on tenglama (PM-36).
# 3. LINKED. After importing a reading, re-run import_tutorials with --republish so the
#    lesson's `"stories": [...]` key attaches it and the Reading card appears.
#
# ══════════════════════════════════════════════════════════════════════
# ── CLARITY IS THE FIRST RULE (inherited from the Prime Russian readings) ──
#
#   * NAME the character in the first sentence and keep using the name.
#   * CHRONOLOGICAL ORDER. Events happen in the order they are written.
#   * ONE THING PER SENTENCE. A new action gets a new sentence.
#   * EVERY NUMBER THE READER NEEDS IS IN THE TEXT, stated once, plainly. Never hide a
#     number inside a subordinate clause, and never make the reader assume one.
#   * NO UNEXPLAINED JUMPS. If the scene moves, say so: Ertasi kuni…, Kechqurun…
#   * The ENDING must land — and in this collection the ending is usually the moment
#     the maths pays off: the right answer, the caught mistake, the better choice.
#   * Test before shipping: read it as a pupil who is fine at reading and shaky at
#     maths. Anywhere they would have to guess a number — fix it.
#
# ── VERSATILE — rotate the genre, never three of the same shape in a row ──
#
#     kundalik hikoya          xat / maktub-javob        kundalik daftar
#     retsept / qoʻllanma      yangilik xabari           sharh (mahsulot, tarif, reklama)
#     ilmiy-ommabop matn       tarixiy epizod            sayohat qaydlari
#     intervyu / soʻrovnoma    sport natijalari          jumboq / sirli hikoya
#
# Retelling real material is encouraged where it is clearer than invention (Misr
# geometrlarining oʻn ikki tugunli arqoni, Fales va piramida soyasi, Gauss bolaligi,
# shaxmat taxtasidagi bugʻdoy). FACTS MUST BE TRUE. When a text is a retelling, say so
# in the Uzbek `summary`.
#
# Modern and everyday is good: telefon tarifi, taksi, dostavka, bozor, futbol, remont,
# elektr hisobi, sinf kassasi. Keep it light and kind.
#
# ── Length curve (guide, not a rule) ──
#   PM-1  … PM-28    90–150 words    a small scene with one calculation in it
#   PM-29 … PM-56   150–200 words    a scene with a beginning, a middle and a decision
#   PM-57 … PM-100  200–280 words    real texts: an article, a report, a retold history
#
# ── Language policy ──
#   Everything is in UZBEK — the text, the title, the terms, the questions, the
#   explanations. Maths appears as HTML exactly as in the tutorials (x<sup>2</sup>,
#   ×, ÷, √, ≤, ≥, π, °, decimals with a comma: 3,5). No English, no LaTeX, no Cyrillic.
#   Bold the lesson's own number work with <strong> where it appears — house style of
#   the Prime collections.
#
# ── Terms (cn-word) ──
#   6–10 in the early readings, 8–12 up to PM-56, 10–16 from PM-57.
#   data-pos is left empty here (verb/adj/adv are for the language collections).
#   Names: the user's pupils — Afsona, Jasur, Sherbek, Dilnoza, Bekzod — plus family
#   and neighbours (buvijon, Karim aka, Nodira opa).
#
# ══════════════════════════════════════════════════════════════════════
# ── ⛔ NO AUDIO ON THIS COLLECTION ──
#
# Formulas, x², 3/4 and 240 000 × 0,3 do not survive text-to-speech. Do NOT run
# gen_corner_audio or import_corner_audio for Prime Math Readings, and do not offer it.
# Korean and English keep their audio; maths gets none.
#
# A batch is therefore: 3 tutorials + 3 practices + 3 readings. That is all.
#
# ── ⚠️ THE ARITHMETIC GATE ──
# Every number in a story must be internally consistent, and the correct MCQ option must
# be exactly what the story's numbers produce. Verify with the batch's scratchpad script
# (verify_pm_<range>.py) before importing. See STYLE_GUIDE_PRIME_MATH.md section 7.
# ══════════════════════════════════════════════════════════════════════
#
# Mark finished ranges with [done].
