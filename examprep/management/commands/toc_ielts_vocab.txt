# Writing rules live in STYLE_GUIDE_VOCAB_IELTS.md. This file is ONLY the ordered group list.
# This is the VOCAB BANK — the table at /examprep/ielts/vocab/ and the word families at
# /examprep/ielts/vocab/roots/. One data file per group; each owns an `order` decade.
# The headline feature is ROOT FAMILIES (lotin/yunon ildizlari):
#     spect → inspect · spectator · perspective · prospect · spectacular
# Levels are BANDS here (level 1 = Band 5 … level 6 = Band 7.5+).
# Status: [done] = imported; [next] = not written yet.
#
# ⚠️ IMPORT ORDER MATTERS. A word may use a root defined in another file, and
# import_vocab errors out rather than silently dropping the word from its family.
# Import in this order, and keep it when you add a group — a new file may reference
# any root above it, never below:
#     1. _vocab_ielts_roots_action.py    (self-contained)
#     2. _vocab_ielts_roots_mind.py      (self-contained; defines the "knowing" roots)
#     3. _vocab_ielts_roots_affix.py     (prefixes/suffixes; may use roots from 1-2)
#     4. _vocab_ielts_data.py            (Task 1 — uses cresc/duc/port from 1, -ion from 3)
#     5. _vocab_ielts_academic.py        (uses roots from 1-3)
#     6. _vocab_ielts_society.py         (uses roots from 1-3)
#     7. _vocab_ielts_environment.py     (uses roots from 1-3)
# Each root is defined in exactly one file — never copy a root definition, or the two
# copies drift apart.
#
# ⚠️ HOMOGRAPH ROOTS. A few forms carry two meanings: port(carry)/port(harbour),
# sol(sun)/sol(alone), mod(measure)/mod(manner), pen(hang)/pen(punish). Name those as
# "sol(sun)" in a word's `roots` list — import_vocab rejects the bare form as ambiguous
# rather than guessing. Adding a second sense means fixing every earlier file that used
# the bare form, so grep for it before you add one.
# ─────────────────────────────────────────────────────────────────────
